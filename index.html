Asistente — Política de privacidad

Asistente es una aplicación de uso estrictamente personal y privado. La usa únicamente su propietario. No está disponible para el público ni recopila datos de terceros.

Datos a los que accede

Con autorización expresa del propietario, la aplicación accede a su Google Calendar (leer y crear eventos) y a su Gmail (leer correos y crear borradores). Nunca envía correos por su cuenta.

Uso de los datos

Los datos se usan solo para que el propietario consulte su agenda y su correo, y para generar recordatorios y resúmenes. Se procesan mediante servicios de inteligencia artificial (Anthropic y OpenAI) solo para responder a sus solicitudes.

Almacenamiento y terceros

La información se guarda en un servidor privado del propietario. No se vende, no se comparte con terceros y no se usa con fines publicitarios.

Uso de datos de usuario de Google

El uso y la transferencia de información recibida de las API de Google cumplen la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El propietario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions.
